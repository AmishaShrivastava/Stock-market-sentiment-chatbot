# 📈 Stock Market Sentiment Chatbot

An AI-powered Stock Market Sentiment Chatbot that analyzes stock-related information and provides sentiment insights using financial data, news, and social media sources.

The project combines a web-based frontend with a FastAPI backend and AI-powered services to help users understand market sentiment for a particular stock.

---

## 🚀 Features

- 📊 Stock market data analysis
- 📰 Financial news analysis
- 💬 Social media sentiment analysis
- 🤖 AI-powered sentiment interpretation
- 📈 Stock-related insights
- 🔍 Stock symbol-based analysis
- 🌐 Interactive web interface
- ⚡ FastAPI backend
- 🔄 Real-time data service integration
- 🧩 Modular backend architecture
